# Kit phase 1 implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** canopy reads `~/.claude/kit.json`, scans every machine's skill folders for every agent, shows the result as a matrix (view and CLI), and links the shared skills into Codex and Hermes; the mini's `~/.claude` becomes a dotclaude checkout.

**Architecture:** A pure core (`src/core/kit.ts`) parses the manifest and turns what a scan saw into cells and actions. `src/core/kitscan.ts` and `src/core/kitapply.ts` run one POSIX shell script per machine through `onHost`, so a local machine and an ssh one (gpd) work the same way. `src/server/kit.ts`'s `KitHub` owns the scans, the routes and the `kit` event; the UI merges each backend's `KitInfo` like the health view does.

**Tech Stack:** Bun, TypeScript strict, React 19, Zustand, `bun:test`. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-14-kit-design.md` (read it first). Phase 1 only: no MCP, no tools, no copies, no UI apply buttons beyond "apply all here" per machine (the spec puts per-cell buttons in phase 3; the CLI is phase 1's apply, and this plan adds the one machine-wide button because the view needs some way to act).

## Global Constraints

- Gates before calling anything done: `bun run typecheck && bun run lint && bun test && bun run build`.
- `src/core/types.ts` stays browser-safe: no Bun or node imports.
- `src/core/kit.ts` stays pure and browser-safe (no `node:path`; it carries its own posix helpers).
- Prose (comments, docs, UI copy) follows the unslop rules: no em dashes, sentence case, plain words.
- Every commit message ends with the line `Claude-Session: https://claude.ai/code/session_01DEgdKaVhnhcGveC62zKQJh` after a blank line, and has no backticks.
- Commits: Eric commits only when he asks. Each task's last step is "commit" and runs only if Eric approved commits for this execution; otherwise leave the change staged and say so. Never push. `main` deploys.
- dotclaude (`~/.claude`) has unrelated uncommitted edits (desk, memory). Never stage, stash or reset them; stage only the paths a task names.
- The mini's half lands only through commits: its canopy builds from the peer-synced tree after a commit and the peer pass, then `bun run redeploy`. Ask Eric for commit and redeploy approval together before Task 9 Step 10.
- Kit never deletes or overwrites an entry it did not place. There is no adopt action in phase 1 (the spec moves it to phase 3). "Placed" means listed in that dir's `.canopy-kit.json`.
- Skill names are slugs: `^[a-z0-9][a-z0-9._-]*$`. A name that fails this is skipped by the scan and reported once in `KitInfo.error`-free `notes`.
- The manifest's agents are unique: one target per agent.
- Relative links for `link` targets: computed from the target dir to the store's skills dir, so `~/.codex/skills/x` gets `../../.claude/skills/x`.

## Review Focus

1. A skills dir holding a real folder with a wanted skill's name (the Mac's Codex `qnap-nas-control` before it moves): expected "foreign", never replaced, never in a plan.
2. ssh to gpd stopping for a Tailscale browser check (the command hangs or exits 255): expected the machine column reads "away" with the reason within the scan timeout, and the other machines still report.
3. A store with local edits whose incoming commits touch none of them (the Mac today): expected `pull` offered and working; with an overlap, the pull fails and the error names git's message.
4. A placed link someone replaced by hand with a folder: expected "drift", and apply leaves the folder alone (remove and relink act only on links).
5. `kit.json` missing or malformed on one backend: expected `GET /api/kit` answers `{ok: false, error}` with no machines, the view says so, and nothing is applied.

Each line has a test in the task that owns the code (Tasks 2, 3, 4, 5).

export type KitMode = "store" | "link" | "copy";

export interface KitMachine {
  name: string;
  /** the canopy backend that owns this machine (`selfName`) */
  backend: string | null;
  /** an ssh host, for a machine no backend runs on */
  ssh: string | null;
  /** the backend that reaches an ssh machine */
  via: string | null;
  /** an ssh machine's dev root; a backend's own is its scan root */
  dev: string | null;
}

export interface KitTarget {
  agent: string;
  /** `~/…` or absolute */
  skills: string;
  mode: KitMode;
  /** null: every machine */
  machines: string[] | null;
}

export interface KitRule {
  /** `*` for all */
  agents: string[];
  machines: string[];
}

export interface KitManifest {
  machines: KitMachine[];
  targets: KitTarget[];
  default: KitRule;
  only: Record<string, Partial<KitRule> & { source?: string }>;
  exclude: string[];
}

export type KitEntryKind = "dir" | "link" | "file";

export interface KitEntry {
  name: string;
  kind: KitEntryKind;
  /** a link's text, as readlink prints it */
  link: string | null;
}

export interface KitSeenTarget {
  agent: string;
  /** the dir, with `~` expanded on that machine */
  dir: string;
  exists: boolean;
  parentExists: boolean;
  entries: KitEntry[];
  /** name → link text canopy placed */
  placed: Record<string, string>;
}

export interface KitStoreState {
  /** skill names git tracks under skills/ */
  tracked: string[];
  branch: string | null;
  ahead: number;
  behind: number;
  /** changed or untracked paths */
  dirty: number;
  fetchFailed: boolean;
}

export interface KitSeen {
  machine: string;
  at: number;
  /** why the machine could not be read; null when it was */
  away: string | null;
  home: string;
  store: KitStoreState | null;
  /** one per target that applies to this machine, the store's first */
  targets: KitSeenTarget[];
  /** source skill name → whether its path exists there */
  sources: Record<string, boolean>;
}

export type KitAction =
  | { kind: "mkdir"; agent: string }
  | { kind: "link"; agent: string; name: string; link: string }
  | { kind: "relink"; agent: string; name: string; link: string }
  | { kind: "remove"; agent: string; name: string }
  | { kind: "pull" };

export interface KitCell {
  machine: string;
  agent: string;
  skill: string;
  state: KitCellState;
  why: string;
}

export interface KitMachineView {
  machine: string;
  seen: KitSeen;
  plan: KitAction[];
}

export interface KitInfo {
  ok: boolean;
  error: string | null;
  machines: KitMachineView[];
  cells: KitCell[];
}

  machine: string;
  done: KitAction[];

/** The kit's pure core (docs/superpowers/specs/2026-10-14-kit-design.md):
 *  the manifest, what each machine should hold, and what to do about it.
 *  Browser-safe: no node imports. */
import type {
  KitAction, KitCell, KitCellState, KitMachine, KitManifest, KitMode, KitRule, KitSeen, KitSeenTarget, KitTarget,
} from "./types";

export const SKILL_NAME = /^[a-z0-9][a-z0-9._-]*$/;
const MODES: readonly KitMode[] = ["store", "link", "copy"];

const isObj = (v: unknown): v is Record<string, unknown> => typeof v === "object" && v !== null && !Array.isArray(v);
const strs = (v: unknown): string[] | null => (Array.isArray(v) && v.every((x) => typeof x === "string") ? v : null);
const str = (v: unknown): string | null => (typeof v === "string" && v !== "" ? v : null);

export function parseKit(raw: unknown): { kit: KitManifest } | { errors: string[] } {
  if (!isObj(raw)) return { errors: ["kit.json is not an object"] };
  if (raw["version"] !== 1) return { errors: ["version: only 1 is known"] };
  const errors: string[] = [];

  const machines: KitMachine[] = [];
  const rawMachines = isObj(raw["machines"]) ? raw["machines"] : {};
  for (const [name, m] of Object.entries(rawMachines)) {
    if (!isObj(m)) { errors.push(`machines.${name}: not an object`); continue; }
    const backend = str(m["backend"]);
    const ssh = str(m["ssh"]);
    const via = str(m["via"]);
    const dev = str(m["dev"]);
    if (!backend && !ssh) errors.push(`machines.${name}: needs backend or ssh`);
    if (ssh && (!via || !dev)) errors.push(`machines.${name}: an ssh machine needs via and dev`);
    machines.push({ name, backend, ssh, via, dev });
  }

  const targets: KitTarget[] = [];
  const rawTargets = Array.isArray(raw["targets"]) ? raw["targets"] : [];
  rawTargets.forEach((t, i) => {
    if (!isObj(t)) { errors.push(`targets[${i}]: not an object`); return; }
    const agent = str(t["agent"]);
    const skills = str(t["skills"]);
    const mode = t["mode"] as KitMode;
    if (!agent || !skills || !MODES.includes(mode)) { errors.push(`targets[${i}]: needs agent, skills and mode`); return; }
    if (targets.some((x) => x.agent === agent)) { errors.push(`targets[${i}]: agent ${agent} appears twice`); return; }
    targets.push({ agent, skills, mode, machines: t["machines"] === undefined ? null : strs(t["machines"]) });
  });
  if (targets.filter((t) => t.mode === "store").length !== 1) errors.push("targets: exactly one target has mode store");

  const rawSkills = isObj(raw["skills"]) ? raw["skills"] : {};
  const rule = (v: unknown, fallback: KitRule): KitRule => {
    const o = isObj(v) ? v : {};
    return { agents: strs(o["agents"]) ?? fallback.agents, machines: strs(o["machines"]) ?? fallback.machines };
  };
  const all: KitRule = { agents: ["*"], machines: ["*"] };
  const only: KitManifest["only"] = {};
  for (const [name, o] of Object.entries(isObj(rawSkills["only"]) ? rawSkills["only"] : {})) {
    if (!SKILL_NAME.test(name) || !isObj(o)) { errors.push(`skills.only.${name}: bad name or not an object`); continue; }
    const entry: KitManifest["only"][string] = {};
    const agents = strs(o["agents"]);
    const ms = strs(o["machines"]);
    const source = str(o["source"]);
    if (agents) entry.agents = agents;
    if (ms) entry.machines = ms;
    if (source) entry.source = source;
    only[name] = entry;
  }
  if (errors.length) return { errors };
  return {
    kit: { machines, targets, default: rule(rawSkills["default"], all), only, exclude: strs(rawSkills["exclude"]) ?? [] },
  };
}

export function expandHome(path: string, home: string): string {
  if (path === "~") return home;
  return path.startsWith("~/") ? `${home}/${path.slice(2)}` : path;
}

const parts = (p: string) => p.split("/").filter((x) => x !== "" && x !== ".");

/** a posix relative path between two absolute dirs */
export function relPath(from: string, to: string): string {
  const a = parts(from);
  const b = parts(to);
  let i = 0;
  while (i < a.length && i < b.length && a[i] === b[i]) i++;
  const up = a.slice(i).map(() => "..");
  const rel = [...up, ...b.slice(i)].join("/");
  return rel === "" ? "." : rel;
}

export const storeTarget = (kit: KitManifest): KitTarget => kit.targets.find((t) => t.mode === "store")!;

export function targetsFor(kit: KitManifest, machine: string): KitTarget[] {
  const mine = kit.targets.filter((t) => t.machines === null || t.machines.includes(machine));
  return [...mine.filter((t) => t.mode === "store"), ...mine.filter((t) => t.mode !== "store")];
}

export function sourcePath(source: string, dev: string): string | null {
  if (source.startsWith("/")) return source;
  if (!source.startsWith("dev:")) return null;
  const rest = source.slice(4);
  if (parts(rest).includes("..")) return null;
  return `${dev.replace(/\/+$/, "")}/${parts(rest).join("/")}`;
}

const glob = (pattern: string, name: string): boolean =>
  new RegExp(`^${pattern.split("*").map((s) => s.replace(/[.+?^${}()|[\]\\]/g, "\\$&")).join(".*")}$`).test(name);

const excluded = (kit: KitManifest, name: string) => kit.exclude.some((p) => glob(p, name));

const sources = (kit: KitManifest) => Object.keys(kit.only).filter((n) => kit.only[n]!.source);

export function skillNames(kit: KitManifest, seen: KitSeen): string[] {
  const tracked = (seen.store?.tracked ?? []).filter((n) => SKILL_NAME.test(n) && !excluded(kit, n));
  return [...new Set([...tracked, ...sources(kit)])].sort();
}

const hits = (list: string[], v: string) => list.includes("*") || list.includes(v);

export function wanted(kit: KitManifest, skill: string, agent: string, machine: string): boolean {
  const o = kit.only[skill] ?? {};
  return hits(o.agents ?? kit.default.agents, agent) && hits(o.machines ?? kit.default.machines, machine);
}

const isSource = (kit: KitManifest, skill: string) => !!kit.only[skill]?.source;

/** the link text a managed entry should carry */
export function wantLink(kit: KitManifest, seen: KitSeen, target: KitSeenTarget, skill: string, dev: string): string {
  const store = seen.targets[0]!;
  if (target.agent === store.agent) return sourcePath(kit.only[skill]!.source!, dev) ?? "";
  return `${relPath(target.dir, store.dir)}/${skill}`;
}

/** whether a skill can exist on this machine at all */
const present = (kit: KitManifest, seen: KitSeen, skill: string) => !isSource(kit, skill) || seen.sources[skill] === true;

export function planKit(kit: KitManifest, seen: KitSeen, dev: string): KitAction[] {
  if (seen.away || !seen.store) return [];
  const out: KitAction[] = [];
  if (seen.store.behind > 0 && seen.store.ahead === 0) out.push({ kind: "pull" });
  const names = skillNames(kit, seen);
  seen.targets.forEach((t, i) => {
    const isStore = i === 0;
    const manage = names.filter((n) => (isStore ? isSource(kit, n) : true));
    const want = manage.filter((n) => wanted(kit, n, t.agent, seen.machine) && present(kit, seen, n));
    if (!t.exists) {
      if (t.parentExists && want.length) out.push({ kind: "mkdir", agent: t.agent });
      else return;
    }
    const byName = new Map(t.entries.map((e) => [e.name, e]));
    for (const name of want) {
      const link = wantLink(kit, seen, t, name, dev);
      const e = byName.get(name);
      if (!e) out.push({ kind: "link", agent: t.agent, name, link });
      else if (name in t.placed && e.kind === "link" && e.link !== link) out.push({ kind: "relink", agent: t.agent, name, link });
    }
    for (const name of Object.keys(t.placed)) {
      if (want.includes(name)) continue;
      if (byName.get(name)?.kind === "link") out.push({ kind: "remove", agent: t.agent, name });
    }
  });
  return out;
}

function cell(kit: KitManifest, seen: KitSeen, t: KitSeenTarget, isStore: boolean, skill: string, dev: string): { state: KitCellState; why: string } {
  const e = t.entries.find((x) => x.name === skill);
  const managed = !isStore || isSource(kit, skill);
  const isWanted = wanted(kit, skill, t.agent, seen.machine);
  if (isStore && !managed) {
    if ((seen.store?.tracked ?? []).includes(skill)) return e ? { state: "ok", why: "" } : { state: "missing", why: "tracked but not checked out" };
    return { state: "local", why: "only on this machine, not tracked in dotclaude" };
  }
  if (!isWanted) return e ? { state: "local", why: "here, but the manifest does not give it to this agent" } : { state: "off", why: "" };
  if (!present(kit, seen, skill)) return { state: "no-source", why: `no ${kit.only[skill]!.source} here` };
  if (!t.exists && !t.parentExists) return { state: "noagent", why: `${t.dir} has no parent; agent not installed` };
  if (!e) return { state: "missing", why: "" };
  if (!(skill in t.placed)) return { state: "foreign", why: `a ${e.kind} canopy did not place` };
  const link = wantLink(kit, seen, t, skill, dev);
  if (e.kind !== "link" || e.link !== link) return { state: "drift", why: e.kind === "link" ? `points at ${e.link}` : `now a ${e.kind}` };
  return { state: "ok", why: "" };
}

export function cellsOf(kit: KitManifest, views: { seen: KitSeen; dev: string }[]): KitCell[] {
  const out: KitCell[] = [];
  for (const { seen, dev } of views) {
    if (seen.away || !seen.store) {
      for (const t of targetsFor(kit, seen.machine)) out.push({ machine: seen.machine, agent: t.agent, skill: "*", state: "away", why: seen.away ?? "no store" });
      continue;
    }
    const names = skillNames(kit, seen);
    seen.targets.forEach((t, i) => {
      const local = t.entries.map((e) => e.name).filter((n) => !names.includes(n) && !excluded(kit, n));
      for (const skill of [...names, ...local]) {
        out.push({ machine: seen.machine, agent: t.agent, skill, ...cell(kit, seen, t, i === 0, skill, dev) });
      }
    });
  }
  return out;
}

/** Reading one machine for the kit: one POSIX sh script through onHost, so
 *  a local machine and an ssh one read the same way. */
import { onHost } from "./exec";
import { SKILL_NAME, sourcePath, targetsFor } from "./kit";
import type { KitEntry, KitEntryKind, KitManifest, KitSeen, KitSeenTarget, KitStoreState } from "./types";

export const KIT_FILE = ".canopy-kit.json";
const SCAN_TIMEOUT = 30_000;
const FETCH_TIMEOUT = 20_000;

/** args: store dir, then `t <agent> <dir>` per target and `s <name> <path>`
 *  per source. Prints tab lines: H home, K tracked skill, G porcelain line,
 *  F fetch failed, N no checkout, D agent dir exists parentExists,
 *  E agent name kind link, P agent placed-json, R name 0|1. */
export const SCAN_SCRIPT = String.raw`
exp() { case $1 in "~") printf %s "$HOME";; "~/"*) printf %s "$HOME/${1#\~/}";; *) printf %s "$1";; esac; }
list() {
  for p in "$2"/*; do
    [ -e "$p" ] || [ -L "$p" ] || continue
    n=${p##*/}
    if [ -L "$p" ]; then printf 'E\t%s\t%s\tlink\t%s\n' "$1" "$n" "$(readlink "$p")"
    elif [ -d "$p" ]; then printf 'E\t%s\t%s\tdir\t\n' "$1" "$n"
    else printf 'E\t%s\t%s\tfile\t\n' "$1" "$n"; fi
  done
}
placed() { [ -f "$2/${KIT_FILE}" ] && printf 'P\t%s\t%s\n' "$1" "$(tr -d '\n' < "$2/${KIT_FILE}")"; return 0; }
store=$(exp "$1"); shift
printf 'H\t%s\n' "$HOME"
if [ -d "$store/.git" ]; then
  git -C "$store" ls-files -- skills | cut -d/ -f2 | sort -u | while IFS= read -r l; do printf 'K\t%s\n' "$l"; done
  git -C "$store" status --porcelain=v2 --branch | while IFS= read -r l; do printf 'G\t%s\n' "$l"; done
else
  printf 'N\n'
fi
while [ $# -gt 0 ]; do
  case $1 in
    t) a=$2; d=$(exp "$3"); shift 3
       pe=0; [ -d "$(dirname "$d")" ] && pe=1
       if [ -d "$d" ]; then printf 'D\t%s\t%s\t1\t%s\n' "$a" "$d" "$pe"; list "$a" "$d"; placed "$a" "$d"
       else printf 'D\t%s\t%s\t0\t%s\n' "$a" "$d" "$pe"; fi ;;
    s) if [ -e "$3" ]; then printf 'R\t%s\t1\n' "$2"; else printf 'R\t%s\t0\n' "$2"; fi; shift 3 ;;
    *) shift ;;
  esac
done
`.replaceAll("${KIT_FILE}", KIT_FILE);

/** the store dir is the store target's skills dir's parent */
const storeDir = (skills: string) => skills.replace(/\/skills\/?$/, "");

export function scanArgs(kit: KitManifest, machine: string, dev: string): string[] {
  const ts = targetsFor(kit, machine);
  const args = [storeDir(ts[0]!.skills)];
  for (const t of ts) args.push("t", t.agent, t.skills);
  for (const [name, o] of Object.entries(kit.only)) {
    const p = o.source ? sourcePath(o.source, dev) : null;
    if (p) args.push("s", name, p);
  }
  return args;
}

const KINDS: readonly KitEntryKind[] = ["dir", "link", "file"];

export function parseScan(machine: string, stdout: string, at: number): KitSeen {
  let home = "";
  const tracked: string[] = [];
  let branch: string | null = null;
  let ahead = 0;
  let behind = 0;
  let dirty = 0;
  let checkout = true;
  const targets: KitSeenTarget[] = [];
  const sources: Record<string, boolean> = {};
  const byAgent = (a: string) => targets.find((t) => t.agent === a);
  for (const line of stdout.split("\n")) {
    const f = line.split("\t");
    switch (f[0]) {
      case "H": home = f[1] ?? ""; break;
      case "N": checkout = false; break;
      case "K": if (SKILL_NAME.test(f[1] ?? "")) tracked.push(f[1]!); break;
      case "G": {
        const g = f.slice(1).join("\t");
        if (g.startsWith("# branch.head ")) branch = g.slice(14);
        else if (g.startsWith("# branch.ab ")) {
          const m = /\+(\d+) -(\d+)/.exec(g);
          ahead = Number(m?.[1] ?? 0);
          behind = Number(m?.[2] ?? 0);
        } else if (!g.startsWith("#") && g.trim()) dirty++;
        break;
      }
      case "D": targets.push({ agent: f[1]!, dir: f[2]!, exists: f[3] === "1", parentExists: f[4] === "1", entries: [], placed: {} }); break;
      case "E": {
        const t = byAgent(f[1]!);
        const kind = f[3] as KitEntryKind;
        if (t && SKILL_NAME.test(f[2] ?? "") && KINDS.includes(kind)) {
          const e: KitEntry = { name: f[2]!, kind, link: kind === "link" ? (f[4] ?? "") : null };
          t.entries.push(e);
        }
        break;
      }
      case "P": {
        const t = byAgent(f[1]!);
        try {
          const j = JSON.parse(f.slice(2).join("\t")) as { placed?: Record<string, string> };
          if (t && j.placed && typeof j.placed === "object") t.placed = j.placed;
        } catch { /* a broken placed file reads as nothing placed */ }
        break;
      }
      case "R": sources[f[1]!] = f[2] === "1"; break;
    }
  }
  for (const t of targets) t.entries.sort((a, b) => a.name.localeCompare(b.name));
  const store: KitStoreState | null = checkout ? { tracked, branch, ahead, behind, dirty, fetchFailed: false } : null;
  return { machine, at, away: null, home, store, targets, sources };
}

/** the last useful line of a failed ssh or sh */
const reason = (stderr: string, code: number) =>
  stderr.split("\n").map((l) => l.replace(/^#\s*/, "").trim()).filter(Boolean)[0] ?? `exited ${code}`;

export async function seeKit(
  kit: KitManifest,
  m: { name: string; host: string | null; dev: string },
  opts: { run?: typeof onHost; env?: Record<string, string>; timeoutMs?: number; now?: () => number } = {},
): Promise<KitSeen> {
  const run = opts.run ?? onHost;
  const now = opts.now ?? Date.now;
  const store = storeDir(targetsFor(kit, m.name)[0]!.skills);
  const fetched = await run(m.host, ["sh", "-c", `cd "$(eval printf %s "$1")" && git fetch -q origin`, "kit-fetch", store], {
    env: opts.env, timeoutMs: FETCH_TIMEOUT,
  });
  const r = await run(m.host, ["sh", "-c", SCAN_SCRIPT, "kit-scan", ...scanArgs(kit, m.name, m.dev)], {
    env: opts.env, timeoutMs: opts.timeoutMs ?? SCAN_TIMEOUT,
  });
  if (r.code !== 0) {
    return { machine: m.name, at: now(), away: reason(r.stderr, r.code), home: "", store: null, targets: [], sources: {} };
  }
  const seen = parseScan(m.name, r.stdout, now());
  if (seen.store && fetched.code !== 0) seen.store.fetchFailed = true;
  return seen;
}

Note on the fetch line: `eval printf %s "$1"` expands a leading `~` on the target; `onHost` single-quotes each argument for ssh, and locally there is no shell expansion, so the script does it.

/** Carrying out a kit plan on one machine: one sh script through onHost.
 *  It acts only on links (and on the dirs it makes), so a real folder is
 *  never replaced or removed. */
import { onHost } from "./exec";
import { KIT_FILE } from "./kitscan";
import type { KitAction, KitApplyResult, KitSeen } from "./types";

/** args: the store dir, then one op per action as 4 words
 *  (`mkdir dir - -`, `link dir name text`, `relink …`, `remove dir name -`,
 *  `pull - - -`). Prints `ok <i>` or `err <i> <why>` per op. */
export const APPLY_SCRIPT = String.raw`
store=$1; shift; i=0
while [ $# -ge 4 ]; do
  op=$1; d=$2; n=$3; l=$4; shift 4
  case $op in
    mkdir) if mkdir -p "$d" 2>/dev/null; then echo "ok $i"; else echo "err $i cannot make $d"; fi ;;
    link) if [ -e "$d/$n" ] || [ -L "$d/$n" ]; then echo "err $i exists"
          elif ln -s "$l" "$d/$n" 2>/dev/null; then echo "ok $i"; else echo "err $i ln failed"; fi ;;
    relink) if [ ! -L "$d/$n" ]; then echo "err $i not a link"
            elif rm -f "$d/$n" && ln -s "$l" "$d/$n"; then echo "ok $i"; else echo "err $i ln failed"; fi ;;
    remove) if [ ! -L "$d/$n" ]; then echo "err $i not a link"
            elif rm -f "$d/$n"; then echo "ok $i"; else echo "err $i rm failed"; fi ;;
    pull) out=$(git -C "$store" pull --ff-only -q 2>&1)
          if [ $? -eq 0 ]; then echo "ok $i"; else echo "err $i $(printf %s "$out" | tr '\n' ' ')"; fi ;;
  esac
  i=$((i + 1))
done
`;

/** writes each `<agent> <dir> <json>` triple to <dir>/.canopy-kit.json */
const PLACED_SCRIPT = String.raw`
while [ $# -ge 2 ]; do
  d=$1; j=$2; shift 2
  [ -d "$d" ] || continue
  printf '%s\n' "$j" > "$d/${KIT_FILE}.tmp" && mv -f "$d/${KIT_FILE}.tmp" "$d/${KIT_FILE}"
done
`.replaceAll("${KIT_FILE}", KIT_FILE);

const dirOf = (seen: KitSeen, agent: string) => seen.targets.find((t) => t.agent === agent)?.dir ?? "";
const storeOf = (seen: KitSeen) => seen.targets[0]!.dir.replace(/\/skills\/?$/, "");

export function applyArgs(seen: KitSeen, actions: KitAction[]): string[] {
  const args = [storeOf(seen)];
  for (const a of actions) {
    if (a.kind === "pull") args.push("pull", "-", "-", "-");
    else if (a.kind === "mkdir") args.push("mkdir", dirOf(seen, a.agent), "-", "-");
    else if (a.kind === "remove") args.push("remove", dirOf(seen, a.agent), a.name, "-");
    else args.push(a.kind, dirOf(seen, a.agent), a.name, a.link);
  }
  return args;
}

export function nextPlaced(seen: KitSeen, done: KitAction[]): Record<string, Record<string, string>> {
  const out: Record<string, Record<string, string>> = {};
  for (const a of done) {
    if (a.kind === "pull" || a.kind === "mkdir") continue;
    const t = seen.targets.find((x) => x.agent === a.agent);
    if (!t) continue;
    const p = (out[a.agent] ??= { ...t.placed });
    if (a.kind === "remove") delete p[a.name];
    else p[a.name] = a.link;
  }
  return out;
}

export async function applyKit(
  seen: KitSeen,
  host: string | null,
  actions: KitAction[],
  opts: { run?: typeof onHost; env?: Record<string, string> } = {},
): Promise<KitApplyResult> {
  const run = opts.run ?? onHost;
  const done: KitAction[] = [];
  const failed: KitApplyResult["failed"] = [];
  if (actions.length === 0) return { machine: seen.machine, done, failed };
  const r = await run(host, ["sh", "-c", APPLY_SCRIPT, "kit-apply", ...applyArgs(seen, actions)], { env: opts.env, timeoutMs: 120_000 });
  const lines = r.stdout.split("\n");
  actions.forEach((a, i) => {
    const line = lines.find((l) => l === `ok ${i}` || l.startsWith(`err ${i} `));
    if (line === `ok ${i}`) done.push(a);
    else failed.push({ action: a, why: line ? line.slice(`err ${i} `.length) : (r.stderr.trim() || `exited ${r.code}`) });
  });
  const placed = nextPlaced(seen, done);
  const words: string[] = [];
  for (const [agent, p] of Object.entries(placed)) words.push(dirOf(seen, agent), JSON.stringify({ placed: p }));
  if (words.length) await run(host, ["sh", "-c", PLACED_SCRIPT, "kit-placed", ...words], { env: opts.env, timeoutMs: 30_000 });
  return { machine: seen.machine, done, failed };
}

/** The kit's server side: scans, routes and the `kit` event
 *  (docs/superpowers/specs/2026-10-14-kit-design.md). */
import { homedir } from "node:os";
import { join } from "node:path";
import { onHost } from "../core/exec";
import { cellsOf, parseKit, planKit } from "../core/kit";
import { applyKit } from "../core/kitapply";
import { seeKit } from "../core/kitscan";
import type { KitAction, KitApplyResult, KitInfo, KitManifest, KitMachineView, KitSeen, ServerEvent } from "../core/types";

export const KIT_EVERY = 10 * 60_000;

export const kitPath = (): string => process.env["CANOPY_KIT"] ?? join(homedir(), ".claude", "kit.json");

export interface KitHubDeps {
  self: string;
  devRoot: string;
  kitPath: string;
  broadcast(ev: ServerEvent): void;
  run?: typeof onHost;
  env?: Record<string, string>;
  /** 0 turns the clock off (tests) */
  every?: number;
  now?: () => number;
}

class KitError extends Error {
  constructor(message: string, readonly status: number) { super(message); }
}

const json = (data: unknown, status = 200) => new Response(JSON.stringify(data), { status, headers: { "content-type": "application/json" } });

interface Mine { name: string; host: string | null; dev: string }

export class KitHub {
  private last: KitInfo = { ok: false, error: "not scanned yet", machines: [], cells: [] };
  private kit: KitManifest | null = null;
  private timer: ReturnType<typeof setInterval> | null = null;
  private scanning: Promise<KitInfo> | null = null;
  private views = new Map<string, { seen: KitSeen; dev: string }>();

  constructor(private readonly deps: KitHubDeps) {}

  start(): void {
    void this.scan();
    const every = this.deps.every ?? KIT_EVERY;
    if (every > 0) this.timer = setInterval(() => void this.scan(), every);
  }

  stop(): void {
    if (this.timer) clearInterval(this.timer);
    this.timer = null;
  }

  info(): KitInfo {
    return this.last;
  }

  private mine(kit: KitManifest): Mine[] {
    const out: Mine[] = [];
    for (const m of kit.machines) {
      if (m.backend === this.deps.self) out.push({ name: m.name, host: null, dev: this.deps.devRoot });
      else if (m.ssh && m.via === this.deps.self && m.dev) out.push({ name: m.name, host: m.ssh, dev: m.dev });
    }
    return out;
  }

  private async read(): Promise<KitManifest> {
    let raw: unknown;
    try {
      raw = JSON.parse(await Bun.file(this.deps.kitPath).text());
    } catch (err) {
      throw new KitError(`kit.json: ${err instanceof Error ? err.message : String(err)}`, 500);
    }
    const r = parseKit(raw);
    if ("errors" in r) throw new KitError(`kit.json: ${r.errors.join("; ")}`, 500);
    return r.kit;
  }

  scan(): Promise<KitInfo> {
    this.scanning ??= this.doScan().finally(() => { this.scanning = null; });
    return this.scanning;
  }

  /** each machine publishes as its own scan ends, so a slow ssh machine
   *  (gpd waiting on a Tailscale browser check) never holds up the others */
  private async doScan(): Promise<KitInfo> {
    let kit: KitManifest;
    try {
      kit = await this.read();
    } catch (err) {
      this.kit = null;
      this.views.clear();
      this.last = { ok: false, error: err instanceof Error ? err.message : String(err), machines: [], cells: [] };
      this.deps.broadcast({ type: "kit", kit: this.last });
      return this.last;
    }
    this.kit = kit;
    const mine = this.mine(kit);
    for (const name of [...this.views.keys()]) if (!mine.some((m) => m.name === name)) this.views.delete(name);
    await Promise.all(mine.map((m) => this.scanOne(kit, m)));
    return this.last;
  }

  private async scanOne(kit: KitManifest, m: Mine): Promise<void> {
    const seen = await seeKit(kit, m, { run: this.deps.run, env: this.deps.env, now: this.deps.now });
    this.views.set(m.name, { seen, dev: m.dev });
    this.publish(kit);
  }

  private publish(kit: KitManifest): void {
    const vs = this.mine(kit).map((m) => this.views.get(m.name)).filter((v): v is { seen: KitSeen; dev: string } => !!v);
    const machines: KitMachineView[] = vs.map((v) => ({ machine: v.seen.machine, seen: v.seen, plan: planKit(kit, v.seen, v.dev) }));
    this.last = { ok: true, error: null, machines, cells: cellsOf(kit, vs) };
    this.deps.broadcast({ type: "kit", kit: this.last });
  }

  async apply(machine: string, actions?: KitAction[], dryRun = false): Promise<KitApplyResult> {
    if (!this.kit) throw new KitError(this.last.error ?? "kit.json not read", 409);
    const view = this.last.machines.find((m) => m.machine === machine);
    if (!view) throw new KitError(`not a machine this backend reaches: ${machine}`, 400);
    if (view.seen.away) throw new KitError(`${machine} is away: ${view.seen.away}`, 409);
    const todo = actions ?? view.plan;
    if (dryRun) return { machine, done: todo, failed: [] };
    const m = this.mine(this.kit).find((x) => x.name === machine)!;
    const r = await applyKit(view.seen, m.host, todo, { run: this.deps.run, env: this.deps.env });
    await this.scanOne(this.kit, m);
    return r;
  }

  async handle(req: Request, url: URL): Promise<Response | null> {
    const path = url.pathname;
    if (!path.startsWith("/api/kit")) return null;
    try {
      if (path === "/api/kit" && req.method === "GET") return json(this.last);
      if (path === "/api/kit/scan" && req.method === "POST") return json(await this.scan());
      if (path === "/api/kit/apply" && req.method === "POST") {
        const body = (await req.json().catch(() => ({}))) as { machine?: unknown; actions?: unknown; dryRun?: unknown };
        if (typeof body.machine !== "string") return json({ error: "machine is required" }, 400);
        const actions = Array.isArray(body.actions) ? (body.actions as KitAction[]) : undefined;
        return json(await this.apply(body.machine, actions, body.dryRun === true));
      }
    } catch (err) {
      if (err instanceof KitError) return json({ error: err.message }, err.status);
      throw err;
    }
    return null;
  }
}

import type { KitAction, KitApplyResult, KitInfo } from "../core/types";

export function actionWord(a: KitAction): string {
  if (a.kind === "pull") return "pull";
  if (a.kind === "mkdir") return `mkdir ${a.agent}`;
  return `${a.kind} ${a.agent}/${a.name}`;
}

const PROBLEMS = new Set(["missing", "drift", "foreign", "no-source", "noagent", "away"]);

export function kitStatusLines(info: KitInfo, machine: string | null): string[] {
  if (!info.ok) return [info.error ?? "kit not read"];
  const out: string[] = [];
  for (const m of info.machines) {
    if (machine && m.machine !== machine) continue;
    const s = m.seen.store;
    if (m.seen.away) out.push(`${m.machine}  away: ${m.seen.away}`);
    else if (s) {
      const bits = [s.branch ?? "no branch"];
      if (s.ahead) bits.push(`${s.ahead} ahead`);
      if (s.behind) bits.push(`${s.behind} behind`);
      if (s.dirty) bits.push(`${s.dirty} changed`);
      if (s.fetchFailed) bits.push("fetch failed");
      out.push(`${m.machine}  store ${bits.join(", ")}`);
    }
    for (const c of info.cells) {
      if (c.machine !== m.machine || !PROBLEMS.has(c.state) || c.state === "away") continue;
      out.push(`  ${c.agent}  ${c.skill}  ${c.state}${c.why ? `  ${c.why}` : ""}`);
    }
    if (m.plan.length) out.push(`  plan: ${m.plan.map(actionWord).join(", ")}`);
  }
  return out;
}

export function kitApplyLines(r: KitApplyResult): string[] {
  return [
    ...r.done.map((a) => `${r.machine}: ${actionWord(a)} done`),
    ...r.failed.map((f) => `${r.machine}: ${actionWord(f.action)} failed: ${f.why}`),
  ];
}

import type { BackendEntry } from "../core/types";

export const KIT_USAGE = "usage: canopy kit [status|apply] [--machine m] [--dry-run] [--backend URL]";

export async function kitCommand(argv: string[], { fail }: { fail: (msg: string) => never }): Promise<void> {
  const args = [...argv];
  const given = take(args, "--backend");
  const machine = take(args, "--machine") ?? null;
  const dryRun = has(args, "--dry-run");
  const sub = args.shift() ?? "status";
  const home = (given ?? process.env["CANOPY_API"] ?? "http://127.0.0.1:7850").replace(/\/+$/, "");
  const homeTarget: Target = { name: "home", urls: [home] };
  const listed = await ask<{ self?: string; backends?: BackendEntry[] }>(homeTarget, "GET", "/api/backends").catch(() => null);
  const targets = given === undefined && listed?.self ? targetsOf(home, listed.self, listed.backends ?? []) : [homeTarget];
  const call = <T>(t: Target, method: string, path: string, body?: unknown) =>
    ask<T>(t, method, path, body).catch((err: unknown) => fail(err instanceof Unreachable ? `${t.name} did not answer: ${err.message}` : errText(err)));
  if (sub !== "status" && sub !== "apply") return fail(KIT_USAGE);
  let failed = false;
  for (const t of targets) {
    const info = await call<KitInfo>(t, "GET", "/api/kit");
    if (sub === "status") {
      for (const line of kitStatusLines(info, machine)) console.log(line);
      continue;
    }
    for (const m of info.machines) {
      if ((machine && m.machine !== machine) || m.seen.away || m.plan.length === 0) continue;
      const r = await call<KitApplyResult>(t, "POST", "/api/kit/apply", { machine: m.machine, dryRun });
      for (const line of kitApplyLines(r)) console.log(line);
      if (r.failed.length) failed = true;
    }
  }
  if (failed) process.exitCode = 1;
}

```ts
import type { KitCell, KitCellState, KitInfo, KitMachineView } from "../../src/core/types";

export interface KitFilter { agent: string | null; machine: string | null; problems: boolean; text: string }

export const GLYPH: Record<KitCellState, string> = {
  ok: "●", missing: "○", drift: "≠", foreign: "◆", local: "·", off: "", "no-source": "∅", noagent: "–", away: "?",
};

export const PROBLEM: ReadonlySet<KitCellState> = new Set(["missing", "drift", "foreign", "no-source", "away"]);

export function mergeKit(byBackend: Record<string, KitInfo>) {
  const cells: KitCell[] = [];
  const machines: KitMachineView[] = [];
  const errors: { backend: string; error: string }[] = [];
  for (const [backend, info] of Object.entries(byBackend)) {
    if (!info.ok) { errors.push({ backend, error: info.error ?? "kit not read" }); continue; }
    cells.push(...info.cells);
    machines.push(...info.machines);
  }
  return { cells, machines, errors };
}

export function columns(cells: KitCell[]): { machine: string; agent: string }[] {
  const seen = new Map<string, { machine: string; agent: string }>();
  for (const c of cells) seen.set(`${c.machine}\t${c.agent}`, { machine: c.machine, agent: c.agent });
  return [...seen.values()].sort((a, b) =>
    a.machine.localeCompare(b.machine) || (a.agent === "claude" ? -1 : b.agent === "claude" ? 1 : a.agent.localeCompare(b.agent)));
}

export function rows(cells: KitCell[], f: KitFilter): string[] {
  const keep = cells.filter((c) =>
    c.skill !== "*" &&
    (!f.agent || c.agent === f.agent) &&
    (!f.machine || c.machine === f.machine) &&
    (!f.problems || PROBLEM.has(c.state)) &&
    (!f.text || c.skill.includes(f.text.toLowerCase())));
  return [...new Set(keep.map((c) => c.skill))].sort();
}

export const cellAt = (cells: KitCell[], skill: string, machine: string, agent: string): KitCell | null =>
  cells.find((c) => c.skill === skill && c.machine === machine && c.agent === agent) ?? null;
```
